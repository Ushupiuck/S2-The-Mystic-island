# The Mystic Island

A Sonic 2 NA Romhack, including multiple modifications to the base game. Examples include:
Additional levels*
Sonic & Knuckles's Priority manager
Sonic & Knuckles's Object manager*
Sonic & Knuckles's Ring manager*
Improved Kosinski & Moduled Kosinski decompressors (Kos+/Kosm+)
KeH Enhanced Sound Driver
Character Selection Screen, alike that of Sonic 2 final*
Bonus & Special Stages*
Too many bugfixes to count


* This element is still W.I.P. or not-implemented
